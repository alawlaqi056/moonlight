# موقع Moonlight Assistance + لوحة الإدارة

موقع ثنائي اللغة (عربي/إنجليزي) لمكتب Moonlight Assistance، ومعه لوحة إدارة على الرابط `/admin/`.

لا يحتاج الموقع إلى أي برنامج على جهازك ولا إلى استضافة مدفوعة. يُنشر مجانًا على GitHub Pages، وقاعدة البيانات مجانية على Supabase.

## ما في هذه الحزمة

| الملف | وظيفته |
|---|---|
| `index.html` | الموقع العام |
| `admin/index.html` | لوحة الإدارة |
| `config.js` | **الملف الوحيد الذي ستعدّله**: يربط الموقع واللوحة بقاعدة البيانات |
| `supabase/schema.sql` | ينشئ الجداول والصلاحيات والبيانات الأولية (44 جامعة ومعهد) |
| `.nojekyll` | يطلب من GitHub نشر الملفات كما هي |

## ماذا تفعل اللوحة؟

- **الجامعات والمعاهد**: إضافة وتعديل وحذف وإخفاء، وترتيبها، ورفع صورة خلفية لبطاقة كل جامعة.
- **الاستفسارات**: كل طالب يملأ النموذج في الموقع تصله بياناته هنا، مع زر مراسلته على واتساب، وحالة (جديد / تم التواصل / منتهي / مزعج) وملاحظات داخلية.
- **النصوص والتواصل**: رقم واتساب والبريد وعناوين الموقع ونبذة المكتب، بالعربية والإنجليزية.
- **الموظفون**: المدير يضيف موظفين. الموظف يرى الاستفسارات ويتابعها فقط، ولا يقدر على تغيير الموقع.

## الخطوة 1: انشر الموقع على GitHub (5 دقائق)

1. ادخل إلى [github.com](https://github.com) وأنشئ مستودعًا جديدًا (New repository)، سمّه مثلًا `moonlight`.
2. اضغط **uploading an existing file** وارفع كل محتويات هذا المجلد (الملفات والمجلدات `admin` و`supabase`).
3. من **Settings ← Pages**: اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)` ثم Save.
4. بعد دقيقة يظهر رابط موقعك: `https://اسمك.github.io/moonlight/` ولوحة الإدارة على `https://اسمك.github.io/moonlight/admin/`.

بهذه الخطوة يعمل الموقع بالمحتوى الجاهز. لوحة الإدارة تعمل بنسخة **تجريبية** لا تغيّر الموقع، حتى تنفّذ الخطوة 2.

## الخطوة 2: فعّل لوحة الإدارة (15 دقيقة، مرة واحدة)

قد تختلف أسماء الأزرار في Supabase قليلًا عن الوصف هنا، لكن المعنى نفسه.

1. **أنشئ مشروعًا** على [supabase.com](https://supabase.com) (New project). اختر اسمًا وكلمة سر لقاعدة البيانات (احفظها) وأقرب منطقة (region) لك.
2. **أنشئ الجداول**: من القائمة اليسرى افتح **SQL Editor** ← New query. افتح ملف `supabase/schema.sql` وانسخ كل محتواه والصقه ثم اضغط **Run**. يجب أن تظهر رسالة نجاح. يمكنك تشغيله مرة ثانية بلا ضرر.
3. **أوقف تأكيد البريد**: **Authentication ← Sign In / Providers ← Email**، وأطفئ **Confirm email** ثم احفظ. هذا يسمح لك بإضافة موظفين دون رسائل تأكيد.
4. **أنشئ حسابك**: **Authentication ← Users ← Add user ← Create new user**. اكتب بريدك وكلمة سر قوية، وفعّل **Auto Confirm User**.
5. **اجعل حسابك مديرًا**: افتح **SQL Editor** وشغّل السطر التالي بعد تعديل البريد (يعمل مرة واحدة فقط):

   ```sql
   select public.bootstrap_first_admin('بريدك@example.com');
   ```

6. **انسخ مفاتيح الربط**: **Project Settings ← API Keys**. انسخ:
   - **Project URL** (يشبه `https://abcdxyz.supabase.co`)
   - **Publishable key** (يبدأ بـ `sb_publishable_`). إن لم تجده فانسخ مفتاح **anon** من قسم Legacy API keys.

   **تحذير:** لا تنسخ أبدًا مفتاح **secret** أو **service_role**. المفتاح العام وحده آمن للنشر، لأن الصلاحيات محمية داخل قاعدة البيانات.
7. **عدّل `config.js`** على GitHub (افتح الملف ← أيقونة القلم) والصق القيمتين بين علامتي الاقتباس، ثم Commit changes:

   ```js
   window.ML_CONFIG = {
     supabaseUrl: "https://abcdxyz.supabase.co",
     supabaseKey: "sb_publishable_..."
   };
   ```

8. **اضبط رابط الموقع** (لازم لرسائل نسيان كلمة السر): **Authentication ← URL Configuration**. اجعل **Site URL** هو `https://اسمك.github.io/moonlight/admin/` وأضفه أيضًا في **Redirect URLs**.
9. افتح `https://اسمك.github.io/moonlight/admin/` بعد دقيقة من الحفظ وسجّل الدخول ببريدك وكلمة سرك.

## الاستخدام اليومي

- **تغيير ما يظهر في الموقع**: بعد الحفظ في اللوحة يتحدّث الموقع عند فتح الزائر له، دون أي رفع جديد إلى GitHub.
- **صورة بطاقة جامعة**: الجامعات والمعاهد ← تعديل ← اختيار صورة. تُصغَّر تلقائيًا. استخدم صورًا تملك حق استخدامها (صورك أو صورًا مرخّصة)، ولا تنسخ صور الجامعات من مواقعها دون إذن.
- **إخفاء بدل الحذف**: زر "إخفاء" يزيل الجامعة من الموقع ويبقيها في اللوحة لتعيدها لاحقًا.
- **إضافة موظف**: الموظفون ← إضافة موظف. اكتب اسمه وبريده، واضغط "توليد كلمة سر"، ثم أرسل له البيانات التي تظهر بعد الإضافة. يستطيع تغيير كلمة السر من "نسيت كلمة السر" في صفحة الدخول.
- **نسيت كلمة السر**: اكتب بريدك في صفحة الدخول واضغط "نسيت كلمة السر؟". يصل رابط إلى بريدك لتعيين كلمة جديدة. (خدمة البريد المجانية في Supabase تحدّ عدد الرسائل في الساعة.)
- **إيقاف موظف**: أزل علامة "مفعّل" أو اضغط "إزالة". لا يمكن حذف آخر مدير.

## ملاحظات مهمة

- **المشاريع المجانية في Supabase قد تتوقف** إذا لم يستخدمها أحد نحو أسبوع. افتح اللوحة مرة في الأسبوع، أو اضغط Restore في لوحة Supabase إن توقفت. يعود كل شيء كما كان.
- **بيانات الطلاب بيانات شخصية** (اسم وهاتف وبلد). تصل إلى قاعدة بياناتك أنت وحدك، ولا يراها إلا المدير والموظفون المضافون. احذف الاستفسارات القديمة التي انتهت، وأخبر طلابك بأنك تحفظ بياناتهم (يظهر هذا في نموذج الموقع تلقائيًا بعد الربط).
- **نسخة احتياطية**: من Supabase ← Table Editor يمكنك تصدير أي جدول بصيغة CSV.
- **نطاق خاص (مثل moonlight.com)**: من Settings ← Pages في GitHub. بعد ذلك حدّث رابط Site URL في الخطوة 8.
- **إن لم يتصل الموقع بقاعدة البيانات** لأي سبب، يعرض المحتوى الجاهز المضمَّن فيه ولا يتعطل.

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| تظهر في اللوحة "نسخة تجريبية" | `config.js` ما زال فارغًا أو لم يُنشر بعد. تأكد من القيمتين وانتظر دقيقة. |
| "البريد أو كلمة السر غير صحيحة" | تأكد من إنشاء المستخدم في Authentication ← Users، وأن كلمة السر صحيحة. |
| "لا توجد صلاحية" بعد الدخول | لم تشغّل سطر `bootstrap_first_admin` بعد، أو كتبت بريدًا مختلفًا. |
| "هذا الإجراء غير مسموح" عند الحفظ | حسابك موظف وليس مديرًا، أو لم يكتمل تشغيل `schema.sql`. أعد تشغيله. |
| لا تصل رسالة نسيان كلمة السر | افحص مجلد الرسائل المزعجة، وتأكد من الخطوة 8، وانتظر قليلًا إن كثرت المحاولات. |
| لا تظهر صورة الجامعة في الموقع | احفظ التعديل في اللوحة وحدّث الصفحة بقوة (Ctrl+Shift+R). |
